## Architecture and maintainability

`content/ui.mjs`, `services.mjs`, `insights.mjs` are the localization/content system. `ContentPage`, `SiteShell`, `EnquiryForm`, `SiteControls` and `WorkMedia` share rendering and interaction. English and Arabic have separate root documents so lang/dir are correct in initial HTML. `lib/site.js` is the authority for routing, metadata, canonical host and schema. `lib/work-videos.js` manages selection; `video-manifest.json` is generated by `scripts/prepare-media.mjs` with optional verified entries from `video-details.mjs`.

The old `content/pages.json`, `public/app.js` and `public/pages.js` remain as historical sources but are not loaded by the new page templates. `scripts/extract-hero.mjs` extracts the existing shader into the active `public/hero.js`. Do not edit obsolete page strings and expect the published pages to change. Regenerate hero.js after editing the extractor. `public/styles.css` and `pages.css` are retained design styles; `localization.css` owns the semantic/RTL/media additions.

## Analytics and attribution

Set `NEXT_PUBLIC_GA4_ID` in the existing Vercel project only if no other GA/GTM installation owns measurement. It loads only after analytics consent. Declining prevents the custom event pipeline; changing consent updates storage permission. `generate_lead` fires only after Formspree returns success; other events are phone_click, service_cta_click, portfolio_interaction, video_start (once per selected playback) and video_complete. No names, emails or enquiry text are sent to analytics.

Consent-aware session attribution records landing path, language, referrer hostname, allowlisted campaign labels and last service path. It starts when consent is granted; it cannot reconstruct browsing before consent. Current-page campaign parameters are included in the Formspree payload. Search Console and Bing tokens use the example environment settings. Account verification, real event delivery, owner receipt/reply of a test enquiry and conversion reporting still require account access or an owner-controlled test.
